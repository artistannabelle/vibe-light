下载安装，三步上手

Vibe Light v1.3

macOS · Windows · 含 App 与一键安装脚本

macOS 12+ 或 Windows 10/11 · Cursor · Python 3

前往 GitHub 下载
1

下载

在 GitHub 选 macOS 或 Windows 的 zip，解压。

2

安装

双击安装脚本
mac：安装 Vibe Light.command
Win：安装 Vibe Light.bat

3

启用

重启 Cursor，打开 Vibe Light。
mac 还需在「辅助功能」里勾选一次。

注意事项

使用前请知晓

若希望上架 Mac App Store，欢迎在 GitHub 留言。

🔒 隐私与安全

  • 只读取 Cursor 本机数据，不上传云端
  • 一键授权需要辅助功能权限
  • 仅供个人学习使用，未经授权请勿商用

⚠️ 常见问题

  • 灯不亮：确认 Cursor 已打开，并重启 Vibe Light
  • 通过无效：检查辅助功能是否勾选正确 App
  • 安装被拦：访达中右键脚本 → 打开
  • Win：解压后双击 安装 Vibe Light.bat，从开始菜单打开 App

场景 & 痛点

痛点直给，解法直给

你用 Cursor 让 AI 写代码，窗口却被飞书、浏览器挡住—— 你不知道 AI 是在跑、在等你，还是已经停了。

痛点
解法
1Cursor 被挡住，看不见 AI 进度
屏幕角落悬浮红绿灯，余光可扫
2AI 等你授权，没切回去，任务卡住
悬浮层红灯一键通过 / 拒绝
3每次都要 ⌘+Tab 切回 Cursor 看状态
悬浮层 + 菜单栏同步，不用切回 Cursor
4Token 花了多少、AI 写了多少行，心里没数
悬浮层实时显示 Token、AI 代码行数
